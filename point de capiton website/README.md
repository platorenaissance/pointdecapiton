# Point de Capiton - Infinite Animation Website

A smooth, responsive website that displays a video as a seamless infinite animation. The video appears to be embedded directly into the codebase with no visible video controls or standard UI elements.

## Features

- 🎬 **Seamless Video Experience**: No visible video controls or UI elements
- 🔄 **Infinite Loop**: Automatic, smooth looping animation
- 📱 **Fully Responsive**: Works perfectly on all devices and screen sizes
- 🚀 **Ultra-Smooth Performance**: Hardware-accelerated playback
- ⚡ **Fast Loading**: Preloaded video for instant playback
- 🎨 **Clean Design**: Full-screen immersive experience

## Technology Stack

- **HTML5**: Semantic markup with video element
- **CSS3**: Responsive design with modern features
- **Vanilla JavaScript**: Smooth playback control and error handling
- **Vercel**: Easy deployment and hosting

## Local Development

1. Clone the repository
2. Open `index.html` in a web browser
3. Or use Vercel CLI: `vercel dev`

## Deployment

This project is optimized for Vercel deployment:

1. Push to GitHub
2. Connect repository to Vercel
3. Deploy automatically
