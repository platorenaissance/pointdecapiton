# Point de Capiton - Infinite Animation

A smooth, responsive Next.js website featuring an infinite video animation.

## Features

- 🎬 Seamless video experience with no controls
- 🔄 Infinite loop animation
- 📱 Fully responsive design
- 🚀 Optimized for Vercel deployment

## Deployment

1. Push to GitHub
2. Connect to Vercel
3. Add environment variable `NEXT_PUBLIC_VIDEO_URL` with your video URL
4. Deploy!

## Video Hosting

For large videos (>25MB), use Vercel Blob or external hosting and set the `NEXT_PUBLIC_VIDEO_URL` environment variable.
